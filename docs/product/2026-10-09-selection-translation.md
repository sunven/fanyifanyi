# 划词翻译

状态：代码实现及自动化检查已完成；浏览器和打包应用的验证边界见下文。

## 已确认的场景

在浏览器中阅读英文技术文章，选中一句话后按快捷键，在原处查看译文并继续阅读。选中文字本身不触发翻译，无需先手动复制。

## 已确认的边界

- 首版仅支持 macOS。
- 保留现有复制后快捷翻译入口，为划词翻译设置独立快捷键。
- 没有选中文字时明确提示，不使用剪贴板中的旧内容代替选区。
- 沿用现有鼠标附近浮窗，按 Esc 关闭并返回来源应用。
- 单词和句子统一显示译文，首版不自动切换到词典。
- 以 Chrome、Safari 普通网页中可选中的文字为首版验收范围；图片和扫描 PDF 使用已有截图翻译。
- 读取选中文字失败时，明确提示可复制后使用复制翻译，不自动使用剪贴板旧内容，也不自动进入截图。
- 默认快捷键为 `Control + Option + D`，支持在设置中改绑或关闭；注册冲突时显示错误并允许改绑。
- 沿用当前默认翻译引擎和中英互译规则，英文译为中文、中文译为英文。
- 成功结果遵守现有历史保存设置。
- 如果取词需要 macOS 辅助功能权限，首次使用时引导授权；未授权时说明原因并提供设置入口，现有复制翻译仍可使用。
- 取词保持剪贴板原有内容不变，不通过模拟 `Command+C` 兜底；读不到选区时明确提示。
- 重复触发相同文字时聚焦已有结果，新文字替换当前内容。
- 浮窗取得键盘焦点，支持复制译文和失败重试；Esc 返回来源应用。
- 在翻译浮窗内再次按划词翻译快捷键时保留当前结果，不把浮窗中的选字作为新任务。

## 验收标准

1. 在 macOS Chrome、Safari 普通网页中选中英文句子，按默认快捷键后，无需手动复制即可在鼠标附近浮窗看到中文译文。
2. 仅选中文字不会发起翻译；单词和句子均显示译文，不自动切换到词典。
3. 未选中文字、无法读取选区或未授权时明确提示，不把剪贴板旧内容提交给翻译引擎。
4. 剪贴板原有内容在取词前后保持不变；失败时不模拟复制或自动启动截图。
5. 浮窗中可复制译文、失败重试，按 Esc 返回来源应用；重复触发遵守上述规则。
6. 划词翻译快捷键可改绑或关闭，冲突可见；现有复制翻译入口保持可用。
7. 使用当前默认引擎，中英互译及成功结果的历史保存遵守现有设置。

- 前端 210 项测试通过，包括快捷键设置、授权入口和会话替换。
- Rust 串行全量测试 62 项通过，1 项已有 OCR 性能测试保持忽略；并行运行时已有宽图 OCR 用例曾失败，单独及串行重跑通过。
- TypeScript 与 Vite 生产构建通过；Vite 提示已有大体积 chunk。
- 本次修改的前端源文件 ESLint、Rust 生产库 Clippy 和 diff 空白检查通过。
- 全仓 ESLint 存在大量已有问题；Clippy `--all-targets` 被已有测试服务器未处理 `read` 返回字节数的问题阻断。本次未修改这些无关代码。

## 浏览器与桌面验证

- 隔离 Chrome 普通网页选区：实际 Rust 取词函数返回完整预期句子，验证通过；临时测试和浏览器会话已清理。
- 打包应用的首次权限授权、完整快捷键到翻译浮窗再 Esc 返回的桌面链路尚未实机验收。工具进程具备权限不代表打包应用已获得权限。
- Safari 受控本地网页中，非编辑段落获得焦点并设置 DOM 选区后，实际 Rust 取词函数返回预期句子；这不是物理鼠标拖选测试，具体过程与限制见技术笔记。
